## 一句话概括

| | 常见做法 | 这套方法 |
|---|---|---|
| 结论怎么来 | 凭经验、凭感觉、凭联想 | **从关系位推导** |
| 同一个输入跑两次 | 可能不同 | **一样** |
| 为什么是这个结论 | 说不清 | **能指到具体元素与规则** |
| 没有明确关系时 | 强行给个说法 | **交汇 → 留白，允许不表态** |
| 换一个领域 | 要重做一套 | **换字典即可** |

**它不承诺预测未来**，做的是：给你一套方法，从一个模糊的领域里把结构捞出来。

## 三张图

### 通用框架 · 方法论流程图

```
换领域 → 元素 → 锚点 → 存在性质 → 属性
                                  ↓
      七档 ← 增减调制 ← 基础三档 ←
       ↓
     混合态 → 物极必反 → 两两查表 → 关系状态 → 关系位 → 结论
                                          ↘ 规则库（可替换）
```

对应 `01_象征物体系.md`：五步 → 第五节；七档 / 混合态 / 物极必反 → 第二节；三态 / 关系位 → 第三节；颜色 → 第四节。

### 塔罗分支 · 塔罗推理链

```
① 五步：一张画 → 元素 → 锚点（圆心）→ 属性
                              ↓
        结论 ← 关系位 ← 关系状态 ← 颜色调制
② 一张牌怎么说：正位写法 → 逆位：锚点偏移 → 四种变化
③ 多张牌怎么说：聚 / 散 → 装配成段 → 红线
```

对应 `02_塔罗体系.md`：正位 / 逆位 → 第三、四节；颜色 → 第六节；6 行表 → 第七节；聚散 → 第八节；输出格式 → 第九节。

### 体系全景 · 三块怎么接起来

```
① 通用主干            ② 塔罗分支              ③ 输出
领域 → 元素 → 锚点     牌面 → 颜色调制          分段 → 互动表 → 总况
  → 属性 → 查表          → 正逆位 → 圆心偏移
  → 三态 → 关系位        → 牌间配对 → 聚与散
  → 结论
       └──────────────┬──────────────┘
                 落成文字 → 分段 → 互动表 → 总况
```

> 图是单文件 `.html`（可交互、明暗主题、**动态流动**），双击用浏览器打开；同目录的 `.png` 是静态版。

## 这两份文档不包含什么

**明确写出来，免得误会：**

| 不含 | 为什么 |
|---|---|
| 78 张牌的牌面原文与字典 | 属于具体领域资产，不在方法本身 |
| 具体牌阵（几宫位、怎么摆） | 属于应用层，方法只规定"怎么算" |
| 实现的参数与调优 | 方法说清规则即可复现，参数是实现细节 |
| 商业化、部署、审核 | 与体系无关，单独成档 |
| 任何收益 / 结果承诺 | 它给"结构"，不给"保证" |

## 边界与口吻

1. **它叫"镜"** —— 核心含义是**照见自身**，不是**预测**。
2. **锚点、性质、属性都由"偏见"而定。** 写下来是因为：只要规则一致，推导就可复现。
3. **留白是特意的。** 三态里的"交汇"不是"没法判断"，是主动留出来的呼吸空间。
4. **规律不等于预测。** 描述的是结构与关系，不是必定发生的未来。
