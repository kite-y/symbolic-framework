# 02 · 塔罗体系

> **这是「象征物体系」在塔罗上的落地。**
> 同一套五步与三态，换一本字典，加一套牌面、一套逆位机制。
>
> 不含实现参数（元素条数、牌阵清单、调参策略）。
> 通用部分见 [01_象征物体系.md](../01_通用框架/01_象征物体系.md)。

---

## 一、塔罗 = 一本字典 + 一套牌面

**塔罗在体系里只有两个身份**：一本**字典**（每个象征物对应什么本体），和一套**牌面**（78 张画）。

> **牌 = 多个象征物的集合。**
> 象征物越多 → 本体信息越多 → **但因为潜意识活动是非逻辑的**
> （可以同时矛盾和自洽），**所以只能"在某种程度上窥探"，不能穷尽。**

牌面分两层：

| 层 | 里面有什么 | 参与什么 |
|---|---|---|
| **视觉层**（背景 / 中景 / 前景） | 颜色、事物、人物、构图、数量 | 全部规则 |
| **空间层**（上 / 下 / 左 / 右 / 前 / 后 / 正 / 背） | 方位 | **只有时间变化用它** |

---

## 二、标注：怎么从原文里认出元素

牌面原文里用四种标注，把「可观察物」显式标出来：

| 标注 | 作用 |
|---|---|
| `[[颜色]]` | 一个颜色元素 |
| `[[象征物]]` | 一个事物 / 人物元素 |
| `[[颜色对立]]` | 声明前面的两个颜色构成**合法对**（不是声明整层有对立） |
| `[[隐藏的图画]]` | 极少见：用于"由隐到显"这一种变化 |

**配对规则**：颜色与**紧邻**的象征物就近成对（颜色 + 它落上去的东西）。

**不算元素的情况**：颜色落在普通名词上（天空、衣服、山）**不构成元素**，也不参与判定。

## 三、正位与逆位

> **"不管正位还是逆位，都是一种信息的呈现，只不过因为视角的变化，所以看到了不同的角度而已。"**

| | 取用什么 |
|---|---|
| **正位** | **常见形象象征**（颜色、事物、人物、背景、构图、数量）+ **副牌象征** |
| **逆位** | **常见衍生象征**中的**视角变化** |

**逆位不是"坏"**，它是**视角变了** —— 同一张牌，换个角度看。

**⚠️ 但逆位不是"照正位改句子"，而是：**

```
圆心（核心词）先偏移  →  正位含义跟着偏移  →  得到逆位
```

> 作者原话："逆位是基于正位的含义以及**核心词（圆心）的偏移**而导致的逆位。
> **圆心的设计就是为了逆位而产生的**。
> 如果说逆位没有核心词的偏移作为锚点就会到处乱说。"

**所以逆位的第一步是"圆心偏到哪儿去了"**，不是"哪句话怎么改" ——
**这就是为什么正位必须写得足够详细**：逆位要顺着正位每一条往回推。

> 参见 [01_象征物体系.md](../01_通用框架/01_象征物体系.md) 的「锚点」一节：锚点固定不变，逆位只挪落点，不动锚点本身。

---

## 四、逆位的四种变化

```
① 程度变化   ← 不独立，【嵌套】在下面几种里
     增强（过于某特质） / 减弱（缺少某特质）

② 方向变化
     完全相反（开始时出问题） ← 不叠程度
     部分相反（过程中出问题） ← 叠程度

③ 显隐变化   ← 都不叠程度
     由显到隐（明确→不明确、具有→潜在、表露→压抑）
     由隐到显（很少，只在 [[隐藏的图画]]）

④ 时间变化   ← 只作用于【空间层】，叠程度
     时间线前后移动：已经 / 正在 / 将要（还未）
```

**"程度"这个概念，在书里是独立的一条；但把"程度嵌套进方向/时间"这个组合方式，是原创。**

**属性不随后天摆设改变** —— 正逆位只改读法，不改零件。

---

## 五、时间变化为什么特殊

**它只管"时间线往前还是往后"，不管"事情成不成"** —— 成不成要看正位含义回溯。

**而且只有【有时间态】的象征物才会发生时间变化**：

| 方位 | 时间态 | 会变吗 |
|---|---|---|
| **右**（未来、争斗、物质、力量、真实…） | 有 | ✅ |
| **上**（高贵、神、潜意识、集体、情感…） | 没有 | ❌ |

**所以时间变化只用在空间层，其他三种只用在视觉层（背景/中景/前景）。**

## 六、颜色：三对合法，只有一对改属性

**颜色在塔罗里要单独处理**（通用原理见 01 的「颜色」一节）。塔罗的具体配方是：

**只有白 / 黑 / 红 / 黄四个颜色会产生对立。** 其他颜色（蓝/绿/紫/彩虹）不参与。

**只有三对合法**：

| 对 | 激烈程度 | 属性 | 含义 |
|---|---|---|---|
| 黄 + 白 | **较温和** | **不变** | 手写：<br>黄「丰盛行动、主动温暖、热烈转化」<br>白「纯粹冷静、被动开端、冷性净化」 |
| 红 + 白 | **较为激烈** | **不变** | 手写：<br>红「积极热情、主动活力、强烈行动」<br>白「消极冷静、被动纯洁、弱化开端」 |
| **黑 + 白** | **最激烈** | **变**：<br>黑→**极阳**<br>白→**极阴** | **"非X"生成**：<br>黑的含义 = 对【白】的原含义逐个加"非"<br>白的含义 = 对【黑】的原含义逐个加"非" |

**五条要记住的**：

1. **只有黑白会改属性** —— 黄白、红白一个属性都不动。
2. **配对顺序无关** —— 黄白 = 白黄，黑白 = 白黑。
3. **`[[颜色对立]]` 标记只指向那两个颜色**，不是声明"整层有对立"。
4. **找法**：从标记往前，最近的能构成合法对的两个颜色。
5. **"非X"只有黑白用** —— 黄白红白是手写词。

**例（黑白）**：

```
原文：一[[黑色]]一[[白色]]的两[[柱子]]（[[颜色对立]]）

黑色：属性 中 → 极阳，含义「无、混沌…」→「非单纯、非纯粹…」
白色：属性 中 → 极阴，含义「单纯、纯粹…」→「非无、非混沌…」
判定：极阳 + 极阴 → 对碰（最激烈）
```

**顺序是死的**：先处理颜色的深浅 → 再处理对立 → **最后才配对判定**。

## 七、塔罗用的基础关系表（6 行）

| 属性1 | 属性2 | 状态 | 偏向 | 关系位 |
|---|---|---|---|---|
| 阴 | 阳 | 对碰 | 无 | 冲突位 |
| 阴 | 阴 | 重叠 | 无 | 和谐位 |
| 阳 | 阳 | 重叠 | 无 | 和谐位 |
| 中 | 阴 | 交汇 | **中偏阴** | 调和位 |
| 中 | 阳 | 交汇 | **中偏阳** | 调和位 |
| 中 | 中 | 重叠 | 无 | 和谐位 |

**这张表是塔罗这一支当前使用的表。** 它有两个特点：

1. **只有 6 行** —— 表里只写一个顺序；反过来的（阳+阴 / 阴+中 / 阳+中）查镜像即可。
2. **不含强度** —— 塔罗这一支**不输出强度**。强度是一种程度量化，
   而**属性的变化只为含义服务，不做计量**。

**极 / 衰 怎么处理**：极阳、衰阳**本质还是阳**，按"阳"查上表；极阴、衰阴同理按"阴"查。

> 例：`深白(阳) + 狗(阳)` → 阳+阳 → **重叠**
> 　　 `极阳 + 阳` → 也是阳+阳 → **重叠**

## 八、多张牌：配对、聚与散

**牌与牌之间不是"有关系"，而是"具体的元素配上了"。**

| 概念 | 规则 |
|---|---|
| **牌间配对** | 只用**还没被本牌组合用掉**的元素；**同层 + 同类目**才配（颜色配颜色、事物配事物；空间层方位只和方位配） |
| **聚（歧点）** | 几张各自取一个**同状态**的组合，凑成一个**整体**；整体一旦形成就不再与谁"对碰"，只带自己的方向往下走 |
| **散（瑕点）** | 一张牌拆成按状态划分的碎片，碎片各自去找对家的同状态组合；**碎片用完即弃**，片数决定最多能连几对 |

**两者的产物都是融合，不是叠加**：不是把两句话并排写，而是问「一个落在另一个上，会变成什么」。

**为什么要有这一层**：一张牌的读法只说明它自己；多张牌放在一起时，如果不处理"谁和谁配得上"，就只能并列陈述，读起来是一串标签而不是一段话。

## 九、输出：按段走，段里三步

**骨架**

```
# {牌阵名}解读：{主题}                    ← 一级标题，全文只有这一个

## 一、{这一组的名字}                      ← 二级标题，按位置组分

### {位置名} · {牌名}（{正逆位}）           ← 三级标题，一张牌一个
  正文 2–5 句：第一句粗体点出表现，再往下说为什么

### 互动                                   ← 这一段的互动，用表格
| 两处 | 前者带给后者 | 后者回给前者 | 合起来是什么 |

**小结**：这一组整体的走向（一两句）

## 二、……

## 六、结构：一条向下的流                   ← 只有存在歧点 / 瑕点时才出现
（先用一句话把整条流串起来，再填表，全部单向）
| 类型 | 从 | 到 | 搬过去的是什么 | 落点变成什么 |

## 最后、总况：{牌名}（{正逆位}）           ← 收尾，标题带牌名
（整篇的落点，一段话）
```

**几条规矩**

| 位置 | 要求 |
|---|---|
| **一级标题** | `{牌阵名}解读：{主题}`，全文一个 |
| **二级标题** | 按**位置组**分，不按单张牌分 |
| **三级标题** | `位置名 · 牌名（正逆位）`；标题里不再重复写"名字——正文" |
| **单牌正文** | 2–5 句；第一句加粗点出它在这个位置的表现 |
| **互动** | **表格**，四列；两端都要写（详见下） |
| **小结** | 段末一句，把这一组收住，不复述单张 |
| **结构段** | **只在有歧点 / 瑕点 / 合成整体时才有**；没有就整节省略 |
| **总况** | 放最后，标题带牌名；正文不按牌分行 |
| **没总况的牌阵** | 末尾**自动补一段短总况**：1–3 句，只对这副牌阵做总结，**不复述某个位置的含义**、不引入新牌 |

**互动是双向的，歧点 / 瑕点是单向的**

| | 方向 | 怎么写 |
|---|---|---|
| **普通配对** | **双向** | 三列：前者带给后者 / 后者回给前者 / 合起来是什么。两边都要填，不能写"A 影响 B"就完事 |
| **歧点** | 单向 | 几张先合成一个整体，整体单方面流出去，不回头 |
| **瑕点** | 单向 | 一张牌拆成碎片，碎片单向流入，用完即弃 |

> 表格列就是照"双向"设计的 —— 单向句填不进第二列。

**三条红线**：

1. **不对未来做绝对判断** —— 不写"会 / 将 / 必然 / 注定"
2. **不做概率化预测、不做人格断言** —— 不写"多半 / 大概率"，不写"你其实是 / 内心是为了"
3. **不做引导** —— 只呈现结构，不给行动指令

**这是"镜"的口吻**：照见，不预言。

## 附：塔罗侧的术语

| 术语 | 一句话 |
|---|---|
| 标注 | `[[颜色]]` / `[[象征物]]` / `[[颜色对立]]` / `[[隐藏的图画]]` |
| 视觉层 | 背景 / 中景 / 前景 |
| 空间层 | 方位（上/下/左/右/前/后/正/背），只参与时间变化 |
