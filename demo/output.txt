
==========================================================================
  ① 一份解读是怎么被算出来的：元素 → 属性 → 配对 → 状态 → 关系位
==========================================================================

【一个人走进一场聚会】
    · 这个人　锚点：适应性　属性：中
    · 这场聚会　锚点：强娱乐性　属性：阳
      这个人 × 这场聚会  →  交汇　偏向：中偏阳　→ 调和位（留白、选择）

【"爱" 与 "伤心"】
    · 爱　锚点：说不清、但依赖触发点的联结　属性：中
    · 伤心　锚点：说得清的低落　属性：阴
      爱 × 伤心  →  交汇　偏向：中偏阴　→ 调和位（留白、选择）

【一个人身上的多个标签】
    · 对外的人　锚点：职业性　属性：阳
    · 对内的人　锚点：松弛　属性：阴
    · 在家人面前　锚点：被照顾　属性：中
      对外的人 × 对内的人  →  对碰　→ 冲突位（矛盾、相对）
      对外的人 × 在家人面前  →  交汇　偏向：中偏阳　→ 调和位（留白、选择）
      对内的人 × 在家人面前  →  交汇　偏向：中偏阴　→ 调和位（留白、选择）

==========================================================================
  ② 极 / 衰 折回基础三档（同一套引擎，与领域无关）
==========================================================================
    阴    → 阴
    阳    → 阳
    中    → 中
    极阴   → 阴　← 折回
    衰阴   → 阴　← 折回
    极阳   → 阳　← 折回
    衰阳   → 阳　← 折回

==========================================================================
  ③ 深浅：档位移动一格（引擎不含具体符号名）
==========================================================================
    阴　深 → 极阴（含义加「过度」）　浅 → 衰阴（含义加「缺乏」）
    阳　深 → 极阳（含义加「过度」）　浅 → 衰阳（含义加「缺乏」）
    中　深 → 阴（含义加「过度」）　浅 → 阳（含义加「缺乏」）

    ⚠️ 引擎只提供「档位怎么动」；
       「哪些名字参与」由领域层决定 —— 那就是 engine/color_rules.py。

==========================================================================
  ④ 领域层是可替换的：本仓库装的是【光/影 · 暖/冷】
==========================================================================
    参与对立的符号：['光', '冷', '影', '暖']
    合法对立对数量：2

    领域声明的层结构：('表层', '里层', '底层')
    引擎实际使用的层：('表层', '里层', '底层')
    → 一致 —— 层结构由领域决定，引擎只是读取

    光 × 影　→　激烈程度：最激烈
        属性：光 → 极阳　影 → 极阴
        含义：光 → ['非暗淡']
        　　　影 → ['非明亮']

    暖 × 冷　→　激烈程度：较温和
        属性：暖 → 不变　冷 → 不变
        含义：暖 → ['向内聚拢', '柔和的持续']
        　　　冷 → ['向外散开', '清晰的停顿']

    光 × 暖　→　不算合法对立对（返回 None）

==========================================================================
  ⑤ 同一张 6 行表，换个输入 → 结论完全不同
==========================================================================
    中 + 阳        → 交汇（偏向 中偏阳）　→ 调和位（留白、选择）
    中 + 阴        → 交汇（偏向 中偏阴）　→ 调和位（留白、选择）
    极阴 + 阳       → 对碰　→ 冲突位（矛盾、相对）
    衰阳 + 阳       → 重叠　→ 和谐位（相关、和谐）
